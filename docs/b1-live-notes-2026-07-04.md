## 판정 체크리스트

- [x] 예스맨: 첫 선택지 비율 85% 미만 (양방향) — 정방향 첫 선택지(쓴다) 23.3%, 뒤집기 첫 선택지(안쓴다) 70.0%. 통과.
- [x] 순서 편향: 뒤집기 전후 차이 ±15%p 이내 — 23.3% → 30.0%, **차이 6.7%p**. 통과.
- [x] 질문 간 분포가 유의미하게 다름 (평균회귀 아님) — EV 5만원(13.3%)이 뚜렷이 낮아 가격 저항 분화 확인. 단, 새벽배송(9900원)과 반찬(3만원)이 7/30 동률 — n=30 우연 범위일 수 있어 n 확대 시 재확인.
- [x] 세그먼트 결이 상식과 부합 — **부분 부합**. 고령층(60~84세) 전원 안쓴다(방향 일관, 상식 부합). 반면 1인가구는 긍정 13%(2/15)로 기대("1인가구 새벽배송 긍정 우세")와 반대 — 2인가구(57%, 4/7)가 최고 긍정. "1인분 식료품 소비량엔 구독이 비효율"이라는 해석이 가능하나 **실측 인터뷰 1순위 확인 항목**.
- [x] reason이 페르소나 속성을 반영 — 단건 프로브에서 확인(25~29세 여성 → "바쁜 일상 속 신선 재료" 논리). 체계적 raw 수집은 LoggingProvider 경로로 후속.

## go/no-go

- **판정: go (조건부)** — 묶음 B2(3층 실측: probes·robustness 배선) 진행 가능.
- 근거: 편향 게이트 2종(예스맨·순서) 명확히 통과, 가격대에 따른 신호 분화 존재, 파이프라인(구조화 응답·missing 처리·usage 집계) 전 구간 정상.
- 조건(후속 확인 3건):
  1. 새벽배송·반찬 분포 동률 — n=100+ 재실행으로 우연 여부 확인 (Batches API 검토 시점).
  2. 1인가구 저항 — 실측 인터뷰에서 최우선 검증할 반직관 신호.
  3. 모델 의존성 — Anthropic 크레딧 확보 시 claude-haiku-4-5로 동일 런북 재실행해 모델 간 결 비교 (CLI `--provider` 플래그로 즉시 가능).
