## 검증 실행 (경고 2건이 진짜인지 별도 확인)

| 실행 | 쓴다 비율 |
|---|---|
| 정방향 (B1) | 23.3% |
| 순서 뒤집기 (B1) | 30.0% |
| 순서 뒤집기 (B2 검증 재실행, 동일 설정) | **53.3%** |
| 패러프레이즈 "…이용하시겠어요?" | 40.0% |

→ 경고는 실재한다. 구체적으로:

1. **마지막 선택지 편향(recency)**: 첫 선택지 쏠림(예스맨)은 0이지만, **뒤에 나열된 선택지를 과선택**하는 패턴. 정방향에선 안쓴다(마지막)가 77%, 뒤집으면 쓴다(마지막)가 30~53%.
2. **실행 간 분산**: 동일 설정 순서-뒤집기 두 실행이 30% vs 53% — n=30에서 gpt-4o-mini의 run-to-run 변동이 ±20%p에 달함.
3. **문구 민감도**: "쓸 의향?"(23%) → "이용하시겠어요?"(40%) — 부드러운 표현이 긍정을 끌어올림.

## 제품에의 함의 (후속 작업 후보)

- **단일 실행 분포를 신호로 쓰면 안 됨** — B2가 그 사실을 계측해서 카드에 박아주는 게 정확히 이 레이어의 존재 이유. 시스템이 설계대로 동작.
- **카운터밸런싱**: 패널 절반은 정방향, 절반은 역순으로 질문해 순서 편향을 상쇄하는 옵션 (simulate 레벨, 후속 이슈 후보 1순위).
- **반복 평균**: repeats≥3의 평균 분포를 기본 신호로 쓰는 옵션.
- **모델 의존성**: 편향의 방향·크기는 gpt-4o-mini 기준 — Claude 교차 실측으로 모델 간 비교 필요 (`--provider anthropic`).

## 후속: 카운터밸런싱 + 반복 풀링 적용 결과 (같은 날)

`--counterbalance --repeats 3` (simulate counterbalance + study repeats 풀링, 커밋 efd741b) 재실행:

| 구성 | 쓴다 비율 |
|---|---|
| 정방향 단일 실행 (B1) | 23.3% |
| 역순 단일 실행 (2회) | 30.0% / 53.3% |
| **카운터밸런스 + 3회 풀링 (n=90)** | **41.1%** |

- 편향 상쇄 추정치 41%는 정방향-only(23%)와 역순-only(30~53%) 사이 — 정방향 단일 실행은 마지막 선택지 편향 때문에 긍정을 **과소평가**하고 있었다.
- 1인가구 저항 패턴은 편향 제거 후에도 유지 (1인 26.7% vs 2인 38.1%) — B1의 반직관 발견이 편향 아티팩트가 아님을 확인.
