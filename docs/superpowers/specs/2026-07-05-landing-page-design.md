# 랜딩 페이지 + /new 분리 설계 — 2026-07-05

## 목적

접속하면 바로 서비스 폼이 보이는 현재 구조 앞에, 제품을 소개하는 히어로
랜딩을 세운다. `/`는 순수 랜딩, 폼은 `/new`로 이동. 기존 에디토리얼
언어(크림 서피스 · Noto Serif KR 헤드라인 · 잉크 텍스트 · hairline)의
연장이며, 새 색상 토큰은 만들지 않는다.

## 결정 사항 (브레인스토밍 합의 — Visual Companion으로 시안 선택)

- **구조**: 별도 랜딩 `/` + 서비스 `/new` (같은 페이지 상단 히어로 아님)
- **히어로 구도**: B안 "신문 1면" — 중앙 정렬 초대형 세리프 헤드라인,
  아래에 리포트 카드 2장이 지면 하단 기사처럼 배치
- **헤드라인 카피**: 2안 "가짜 90명" (정직함을 무기로)
- **랜딩 섹션**: 히어로 + 샘플 리포트 미리보기 + 작동 방식 3단계 +
  정직 면책 (샘플 갤러리는 /new에 잔류)

## 라우팅

| 경로 | 내용 |
|---|---|
| `/` | 랜딩 (신규) — 완전 정적, DB 접근 없음, 프리렌더 |
| `/new` | 서비스 페이지 — 현재 홈(page.tsx)의 h1·lede·disclaimer·ReportForm·갤러리를 그대로 이동. `revalidate = 3600` 유지 |
| `/r/[id]` | 무변경. 단 "← 새 리포트 만들기" backlink는 `/new`로 |

- 마스트헤드 로고 링크는 `/` 유지 (랜딩이 새 홈)
- 리다이렉트 불필요 — 기존 공유 링크 무영향

## 랜딩 콘텐츠 (위에서 아래로)

### 1. 히어로 — 신문 1면

- kicker (小 대문자풍 라벨): `창업자를 위한 0차 시장검증`
- 헤드라인 (중앙, 초대형 세리프, 데스크톱 ~56px/모바일 ~34px):
  `진짜 고객을 만나기 전,` 줄바꿈 `가짜 90명에게 먼저 물어보세요`
  — "가짜 90명"을 `<span>`으로 감싸 `border-bottom: 3px solid var(--accent)`
  (다크에서는 --accent 다크 토큰 자동 적용)
- 서브카피: `통계청 인구 분포를 흉내 낸 합성 패널 — 실제 여론이
  아니라서, 오히려 솔직하게 쓸 수 있습니다`
- CTA 버튼: `리포트 만들기 — 약 1분` → `/new` (기존 잉크 버튼 문법)
- 보조 텍스트 링크: `샘플 리포트 보기 →` → `/r/BAJnsFMKrF`

### 2. 리포트 카드 2장 (정적 재현)

- 실제 "한눈에 보기" 카드 마크업을 **정적으로 재현** — 실제 스모크
  리포트(BAJnsFMKrF)의 수치 사용: "반응이 뚜렷하게 긍정적이에요",
  "10명 중 9명이 '있다'", 파랑/빨강 분포 바
- 두 번째 카드: 세그먼트 톤 — "수도권 거주자의 반응이 가장 좋았어요" +
  세그먼트 바 축약
- 각 카드에 작은 라벨 `예시 리포트` 명시 (synthetic panel 과장 금지)
- 카드 전체가 `/r/BAJnsFMKrF` 링크
- **라이브 DB 연동 금지** — 랜딩은 항상 즉시 뜨고 절대 깨지지 않아야 함

### 3. 작동 방식 3단계

아이콘 없이 세리프 큰 숫자(①②③ 대신 1/2/3 세리프 숫자) + hairline 구분:
1. `질문을 입력합니다` — 선택지 2~4개, 200자 이내
2. `합성 패널 90명이 응답합니다` — 통계청 인구총조사 분포로 구성, 약 1분
3. `리포트와 공유 링크를 받습니다` — 쉬운 요약 + 세그먼트 분석 + 다음 행동 처방

### 4. 정직 면책 — "이 서비스가 하지 않는 것"

기존 amber 콜아웃 문법으로:
- 실제 여론조사가 아닙니다 — AI가 인구 구성을 흉내 내 답한 결과입니다
- 고객 인터뷰를 대체하지 않습니다 — 인터뷰 전에 가설을 좁히는 용도입니다
- 수치는 방향 신호입니다 — 실제 시장 반응·구매율이 아닙니다

### 5. 하단 CTA 반복 + colophon

- CTA 버튼 반복 (`리포트 만들기 — 약 1분` → `/new`) + `무료 · IP당 하루 3회`
- 기존 colophon(레이아웃 공유) 그대로

## 구현 형태

- `app/src/app/page.tsx` → 랜딩으로 전체 교체 (정적 서버 컴포넌트,
  마크업만·로직 없음). `revalidate`/`getStore` import 제거
- `app/src/app/new/page.tsx` → 기존 홈 내용 이동 (loadGallery·ReportForm
  로직 무수정, import 경로만 조정: `../../lib/...`, `../report-form.js`)
- `app/src/app/r/[id]/page.tsx` → backlink 2곳 `href="/new"`로
- `globals.css`에 `.landing-*` 스타일 블록 추가 — **기존 CSS 변수 토큰만
  사용** (신규 색 금지), 다크 모드 미디어쿼리 앞(갤러리 섹션 근처)에 삽입.
  다크 전용 오버라이드가 필요하면 기존 다크 블록에만 추가
- 모션: CTA/카드 hover 상태 정도로 절제 (스크롤 애니메이션·패럴랙스 금지)
- 반응형: 375px(모바일)에서 헤드라인 축소·카드 1열 스택
